# 检测场景

12个苹果样本分4批，每个样本初检P01为<0.01mg/kg，采样日标准限量0.005，因此不确定。次日同样本同方法复检0.004且LOD0.001，判为PASS并替代原报告。每样本P02为30ug/kg，超过0.02mg/kg，仍FAIL。最终24项目，12PASS、12FAIL，四批均FAIL。脏批额外含缺LOD、同版冲突、错列、空行与重复表头。

## 分送两站（cross_station.csv）

同一样本分送 A、B 两站检测，报告带 `station` 列。M6 按样本/残留项目汇总各站结论后再判批次，出证裁决由项目结论驱动：

| 样本 | A站 | B站 | 其他 | 项目裁决 | 依据 |
|---|---|---|---|---|---|
| S101 | PASS | FAIL | — | 暂缓 | 两站冲突且无仲裁报告 |
| S102 | PASS | FAIL | 仲裁站 PASS | 可采信（仲裁） | 仲裁报告 01005 判定 PASS |
| S103 | PASS | 缺LOD隔离 | — | 仍需补齐 | B站异议报告依据不完整 |
| S104 | PASS | PASS | — | 可采信 | 两站结论一致 |
| S105 | FAIL | FAIL | — | 可采信 | 两站结论一致 |
| S106 | PASS | PASS | — | 可采信 | 两站结论一致 |

批级取最严：B101 暂缓（含冲突样本）、B102 补齐（含依据不全样本）、B103 可采信。存在暂缓批次时本次不得出证；B102 补齐后仍保留 B101 的暂缓，只有全部批次可采信且报告账、证据账、批次判级三者对平，才判“可出证”。两站原始报告均进入归档，不因冲突被丢弃。
